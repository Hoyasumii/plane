TypeScript · API v1 + v2 · MCP · CLI

A API do Plane, tipada de ponta a ponta

Um SDK TypeScript para a API do Plane, com um servidor MCP e uma CLI construídos sobre ele. Use-o no código, a partir de um agente de IA ou no terminal: os três compartilham o mesmo cliente.

Começar →GitHub
$ npm install @hoyasumii/plane
@hoyasumii/plane

SDK

Um cliente tipado para a API v1 e toda a superfície v2: 90 recursos, listas de campos que restringem o tipo de retorno em tempo de compilação e linhas buscadas que navegam até seus filhos.

const eng = await client.v2.workspaces.projects.retrieve("acme", "ENG");
await eng.workItems.create({ name: "Fix login bug", state: "Todo" });
plane-mcp

Servidor MCP

O Plane para o Claude Code, o Codex, o OpenCode ou qualquer cliente MCP: ferramentas de tarefa que trabalham por chave e por nome, mais três ferramentas genéricas que alcançam todo método v2.

npx plane mcp config
npx plane mcp install
plane

CLI

Cada ferramenta MCP como um comando de terminal, mais plane mcp para rodar o servidor em segundo plano, iniciá-lo no login e registrá-lo nos seus clientes.

npx plane get-issue --key ACME-14
npx plane list-my-issues --project ACME
