Class: InitiativeEpics

Defined in: src/api/Initiatives/Epics.ts:16

Initiative Epics API resource

Deprecated​

Use client.initiatives.workItems. The /epics/ endpoints are preserved for backward compatibility. Server-side they share one implementation and one association model with /work-items/, so any work item type is accepted and returned here despite the name; the request field is spelled epic_ids only because it predates the unified model.
